Текущий репозиторий: https://github.com/sheninaliudmila-afk/study-planner  
Владелец GitHub: **sheninaliudmila-afk**.

## Запуск

Разместить три файла приложения рядом и открыть в обычном браузере. Для устойчивого хранения нужен постоянный origin; файловые просмотрщики iOS могут не выполнять JavaScript и не сохранять localStorage. Тестовые npm-зависимости приложению не нужны.

## Сохранность данных и публикация

Смена аккаунта GitHub не переносит браузерные записи. Перед сменой адреса сайта сохранить JSON-экспорт из прежнего приложения, затем восстановить его на новом адресе через проверенный импорт. Не импортировать демонстрационные данные вместо актуальных записей.

Публикация новой версии и слияние в main требуют отдельного согласия владельца. Этот репозиторий пока не объявляется опубликованным сайтом. Старый сайт/репозиторий упоминаются только как источник истории; их доступность не является условием запуска трёх исходных файлов.
