Дата: 8 ноября 2026, Europe/Moscow. Владелец прямо поручил опубликовать учебную версию и загрузить её на GitHub; это разрешение заменяет прежний запрет на основную публикацию для этой поставки. Личный закрытый драфт не превращается в публичный.

**Вопрос по учебному заданию:** «Всё ли выполнено по ТЗ?»

**Ответ нейросети:** обязательная функциональность ТЗ 3.0 с изменениями 3.1 и последующими поручениями владельца реализована. Доступная автоматическая проверка пройдена: 637 проверок, ошибок в итоговом прогоне 0. Проект технически готов для публичной сдачи. Полную ручную приёмку на настоящем iPhone/Safari/VoiceOver и одинаковую производительность на всех устройствах утверждать нельзя: эти проверки недоступны среде.

## Доказательства

- [637 проверок и SHA256 исходников](test-evidence/grouping-release/results.json): 369 браузерных групп в Chromium/Firefox/WebKit, 268 расчётных случаев в UTC, Europe/Moscow, Europe/Berlin и America/New_York.
- [Аудит и комплект](GROUPING_RELEASE_ACCEPTANCE.md); [план](plan.md).
- Нагрузочный набор: 600 занятий (включая 100 шаблонов серий), 500 заданий, 1000 записей времени. Первый экран: Chromium 1374 мс, Firefox 1184 мс, WebKit 1095 мс. Недельный календарь: 237/421/163 мс соответственно. Это измерения среды тестирования, не гарантия скорости любого телефона.
- Runtime-файлы публичной поставки не меняются относительно проверенного состояния. Публикация дополнительно проверяется по публичному HTTPS-адресу без учётной записи.

## Практические пределы

localStorage принадлежит браузеру и origin. Между посетителями и устройствами синхронизации нет. При смене адреса нужен экспорт/импорт JSON. Межвкладочная проверка версии не является общей транзакцией браузерного хранилища. Локальный file:// не имеет кросс-браузерной гарантии сохранения — для устойчивого адреса опубликована HTTPS-версия.

Не проверены: реальный iPhone/Safari/VoiceOver, локальный запуск на устройстве владельца, создание Google-документа в его аккаунте и авторизованная программа внешней учебной платформы. Облачная синхронизация, хранение вложений и извлечение закрытой программы через API не входят в обязательную автономную поставку.

Публичная сборка содержит общий код и стартовую пустую базу. Предоставленная владельцем программа курса, старый финансовый JSON и браузерные конспекты не публикуются. Закрытый драфт сохраняет свой отдельный адрес и аудиторию.

## Способ публикации

PR №1 и №2 слиты в main по поручению владельца. Попытка включить GitHub Pages через подключение отклонена GitHub: HTTP 403 «Resource not accessible by integration». Публичная версия размещена отдельным Site с доступом public, без изменения закрытого личного драфта. Условие задания «загрузить на GitHub и опубликовать» выполняется ссылкой на публичный репозиторий и ссылкой на открытый сайт. GitHub Pages не объявляется включённым.
