# Уточнения владельца — курс, модули и цель, 08.11.2026

Эти пользовательские уточнения имеют приоритет над прежним описанием интерфейса и расчёта прогресса курса. Исходные ТЗ 3.0/3.1 сохраняются как документы основания; их текст не переписывается задним числом.

1. Основной вход в обучение — название курса. Затем пользователь задаёт все модули, начало и дедлайны; занятия заполняются позже внутри выбранного модуля. Предмет и преподаватель не должны быть обязательным первым шагом. Направления и прежние предметы сохраняются в данных и доступны в дополнительном виде структуры.
2. Модуль — прежняя запись Topic; её ID, название, занятия, задания и конспекты не заменяются. Курсы остаются независимыми по преподавателям. Для курса без явно выбранного предмета используется отдельный контейнер в выбранном направлении, без привязки к случайному существующему предмету.
3. В курсе есть собственная текстовая цель. Процент этой цели совпадает с полным прогрессом курса; 100% означает достижение, возврат элемента в план снимает достижение. Существующие самостоятельные цели всех четырёх типов сохраняются как дополнительная возможность.
4. Полный план курса учитывает все активные конечные занятия и задания, включая будущие вхождения конечных серий, без дублей материализованных записей. Пустой модуль остаётся одним невыполненным элементом; его можно явно отметить пройденным без создания вымышленных занятий. Когда занятия добавлены, процент считается по ним и заданиям. Частичное задание даёт точную долю отмеченных шагов. Пока хотя бы один шаг/элемент не завершён, округление не поднимает процент до 100. Направление/предмет суммируют элементы курсов с теми же весами. Пустой курс — «нет плана».
5. Даты определяют расписание и просрочки. Само наступление даты не означает выполнения. Общие старые цели Tasks сохраняют прежнюю формулу; именно цель курса явно связана с полным планом курса.
6. Таймер не определяет прогресс курса. Необязательный учёт времени скрыт по умолчанию и включается в настройках; активный таймер всегда остаётся доступным. История времени и самостоятельные цели Hours не удаляются.
7. Изменить, выше/ниже, архив, удалить — иконки под основными действиями; у каждой есть доступное название, подсказка и область касания не менее 44×44 px.
8. Найденная личная структура из копии 3 ноября сохраняется в личном комплекте отдельно от публичного репозитория. При пустом хранилище личный HTML загружает её; существующие данные не заменяются автоматически. Добавление отсутствующих записей предлагает проверенное объединение с приоритетом локальных ID и резервной копией. Более поздние изменения в личном браузере iPhone отсюда недоступны.
9. Main и публикация остаются без изменений до отдельного согласия владельца. Эти изменения — уточнение шага 3; шаг 4 остаётся отдельной сквозной приёмкой.
