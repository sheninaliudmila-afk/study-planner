# Уточнение: программа курса до подробных занятий — 08.11.2026

Владелец показал пример платформы с курсами и настройками плана и уточнил два способа получения программы: предоставить помощнику доступную ссылку на платформу либо вручную сначала ввести все модули со сроками и количеством занятий.

## Текущая поставка

- В курсе есть единый редактор «Программа и расписание»: начало обучения, дата экзамена, общий дедлайн, ссылка на платформу, выбранные дни недели и полный список модулей.
- Для каждого модуля задаются название, начало, срок и количество занятий. 0 — количество пока неизвестно. Ограничение — целое 0–1000 занятий в модуле, до 200 строк в одном редакторе.
- Новые строки можно добавлять, убирать и переставлять. Существующие модули не удаляются из редактора программы; для удаления используется прежняя отдельная операция с подтверждением, копией и Undo.
- Программа сохраняется целиком только после нажатия «Сохранить». Ошибка в любой строке или отказ записи оставляет исходное состояние и весь черновик. Открытие программы не изменяет данные.
- Существующие ID, уроки, конспекты, задания, история времени, архив и самостоятельные цели сохраняются. Сохранение количества не создаёт вымышленные занятия. Уменьшение количества не удаляет уже созданные.
- В знаменатель прогресса входят как минимум запланированные занятия, даже если ещё не заполнены подробности. Для модуля используется максимум из введённого количества и фактических вхождений занятий; задания добавляются отдельно. Завершение пустого модуля недоступно, если для него уже указано положительное количество занятий.
- Выбранные дни недели используются для предложения ближайшей свободной даты при добавлении занятия в модуле, с учётом начала и сроков. Предложение можно изменить. Это не автоматическая генерация всех уроков.
- Дата экзамена видна в курсе, календаре и напоминании внутри открытой страницы.

## Получение программы по ссылке

Предоставленная страница SohoLMS была проверена: она перенаправляет неавторизованный браузер на вход. Список модулей, сроки и число занятий не получены; импорт с этой платформы не объявляется выполненным. Авторизация iPhone не переносится в среду помощника. Пароль или cookie в чат не запрашиваются. После появления разрешённого доступа либо предоставления программы как документа/снимков помощник сможет подготовить структуру; до того работает полноценный ручной редактор.

В браузерном приложении ссылка — безопасный переход на платформу. Она не выдаётся за работающий универсальный импорт из любого закрытого кабинета. Ограничения/блокировки входа не обходятся.
