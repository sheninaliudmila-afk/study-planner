# Группировка курсов и комплект для использования — 08.11.2026

- Курсы собраны по направлениям в отдельные сворачиваемые блоки. Видны название направления и число курсов, доступны добавление курса сразу в нужное направление и прежний перенос курса.
- Пустое активное направление остаётся доступно для создания курса. Состояние свёрнутых блоков сохраняется отдельно от самих курсов.
- Первые уровни крупнее предыдущей версии; шрифт последовательно уменьшается: направление → курс → модуль → занятие. Сохранена полная старая иерархия с предметами.
- «Главная» — первый пункт навигации. Последний открытый раздел и пользовательские записи не сбрасываются.
- Провести текущий аудит шагов и отделить техническую готовность от приёмки владельцем на реальном устройстве.
- Предоставить ZIP-комплект, самостоятельный HTML и понятную инструкцию. Данные текущего браузера не выдавать за включённые в архив: помощнику доступны только явно предоставленные материалы.
- Обновляется существующая закрытая площадка с тем же адресом и доступом только владельца. main и основной сайт без отдельного согласия не изменяются.

Заполненные направления показаны первыми; пустые при первом открытии свёрнуты. Ручное состояние раскрытия сохраняется.
