# Последнее уточнение: заполненный драфт, лекции и ручное завершение

Владелец прямо поручил заполнить веб-драфт по присланным скриншотам, применять тот же процесс к следующим курсам, оставить темы необязательными, добавить место для лекций/заметок и отмечать завершение модуля только по действию владельца. Общий срок курса и дни занятий владелец заполнит самостоятельно; сроки модулей пока пустые.

- В закрытую тестовую площадку добавляется только программа, прямо предоставленная для заполнения. Старая финансовая резервная копия туда не переносится. В публичном GitHub находятся общий код и синтетические тесты, без личной программы.
- Заполнение добавляет отсутствующие курс, модули и известные названия лекций. ID и записи пользователя не заменяются. Повторное открытие не дублирует программу. Новая версия источника добавляет новые записи, сохраняя заметки, сроки и ручные отметки. Удалённые пользователем записи не возрождаются при обычной перезагрузке.
- Номер модуля на платформе сохраняется отдельно, без перенумерации. Неизвестные лекции, даты, длительность, дедлайны и цель курса не придумываются.
- Лекция — материал без обязательной даты: название, необязательная тема, ссылка http(s), заметки/конспект. Для календарного занятия остаётся отдельный редактор. Файлы/видео в localStorage не загружаются.
- Темы — необязательные подписи лекций внутри конкретного модуля, не обязательный новый уровень иерархии.
- Есть заметки курса, модуля и лекции; они сохраняются и входят в JSON. Удаление лекции подтверждается, сохраняет копию и поддерживает Undo.
- Новые и перенесённые модули имеют ручную отметку «Модуль пройден». Проценты и галочки со снимков сохраняются справочно, не проставляют эту отметку. Отметка пользователя завершает весь модуль, не фальсифицирует статусы и даты отдельных занятий/заданий. Снятие отметки возвращает расчёт по фактическому плану. Пока ручное завершение не подтверждено, автоматически выполненный план не считается окончательным 100%.
- Старые записи без новых свойств сохраняют совместимость. Ключ studyPlanner:v1 и схема 2 не меняются. Заполнение и запись атомарны относительно одного setItem; конфликт другой вкладки и ошибка хранилища не должны терять данные.
- Main и основной сайт не изменяются. Обновляется существующий owner-private драфт по прежнему адресу.
