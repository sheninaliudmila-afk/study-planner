# Как открыть публичный планировщик

Публичное приложение: https://study-planner-coursework-public-20261108.fondlyric2.chatgpt.site/

Исходники: https://github.com/sheninaliudmila-afk/study-planner

Откройте приложение браузером на телефоне или компьютере. Вход не требуется. При первом открытии есть два стартовых направления и пустая личная база. Создайте курс, заполните модули и добавьте занятия. «Главная» — первый пункт меню; в «Обучении» курсы сгруппированы по направлениям. Нажатие на заголовок сворачивает группу. «Перенести курс» сохраняет все его материалы.

## Где хранятся записи

Записи находятся в localStorage именно вашего браузера и адреса сайта. Другие посетители их не видят. Между компьютером, телефоном и другими браузерами автоматической синхронизации нет. Публичная версия не включает личную программу и конспекты владельца проекта. Его прежняя закрытая версия остаётся отдельной.

Для резервной копии: «Настройки» → «Экспорт JSON». Файл не нужно редактировать. На другом устройстве откройте «Настройки» → «Импорт JSON (объединить)» и выберите резервный файл. При одинаковых ID сохраняется местная запись. Для точного восстановления есть «Импорт JSON (заменить всё)» с подтверждением. Сохраните исходный экспорт отдельно.

## Запуск из файлов

На GitHub выберите Code → Download ZIP, распакуйте архив, откройте index.html браузером. index.html, style.css и script.js должны лежать рядом. Сборка и установка библиотек не нужны. Другие файлы репозитория — документация и тесты.

В самостоятельном комплекте Study-planner.html уже содержит стили и код. На Mac сначала распакуйте ZIP, затем откройте HTML браузером. Просмотрщик архивов не запускает приложение. Поддержка сохранения file:// зависит от браузера и пути файла; для устойчивого адреса рекомендуется публичная HTTPS-версия. Скачивание HTML не переносит записи текущего браузера — для переноса используйте JSON.

## Проверка учебного задания

PUBLIC_SUBMISSION.md содержит ответ нейросети о соответствии ТЗ. Пройдены 637 автоматических проверок и отдельная проверка публичной версии без входа. Настоящий iPhone/Safari/VoiceOver, локальные файлы на вашем устройстве и создание Google-документа в вашем аккаунте требуют проверки на соответствующем устройстве.
