# Как пользоваться планировщиком

## Самый простой вариант — прежняя закрытая ссылка

Откройте ссылку, полученную в чате, в том же браузере iPhone. Это сохраняет доступ к записям этого браузера. Обновите страницу, чтобы увидеть новую группировку. Адрес не включён в публичные документы проекта.

«Главная» — первый пункт меню. В «Обучении» курсы сгруппированы по направлениям: нажмите на заголовок, чтобы свернуть или развернуть направление. Настройка сохраняется. Кнопка «+ Курс в этом направлении» сразу выбирает нужное направление. «Перенести курс» меняет направление вместе со всеми материалами.

## На компьютере — один HTML-файл

1. Скачайте `Study-planner.html` из сообщения или распакуйте ZIP-комплект.
2. Откройте `Study-planner.html` браузером Chrome, Safari или Edge: двойным нажатием либо «Открыть с помощью» → браузер. Доступ к интернету для самого планировщика не требуется. Google и внешние ссылки требуют интернет.
3. Если предпросмотр показывает «Архивы не поддерживаются», это только просмотрщик ZIP. Сначала скачайте ZIP и распакуйте его. На Mac двойное нажатие ZIP создаст обычную папку. Не запускайте HTML внутри предпросмотра архива.

Вариант для размещения на сайте: `index.html`, `style.css`, `script.js` должны лежать в одной папке. Сборка и установка пакетов не нужны. `Study-planner.html` уже содержит стили и код внутри — соседние файлы ему не требуются.

## Где находятся записи

Записи и конспекты сохраняются в конкретном браузере по конкретному адресу. Сайт, локальный HTML, другой браузер и другой телефон не синхронизируются автоматически. Не очищайте данные браузера и не перемещайте локальный HTML после начала работы: доступность записей для `file://` зависит от браузера и пути файла.

Комплект с предоставленной программой содержит известные модули и названия лекций. Он не содержит конспекты, которые вы вводили в браузере: помощник не имеет к ним доступа. Старый финансовый JSON также не включён и не заменяет текущие записи.

Чтобы перенести свои записи, на прежнем устройстве откройте «Настройки» → «Экспорт JSON» — это сохранит файл резервной копии, его не нужно редактировать. В новой копии выберите «Настройки» → «Импорт JSON (объединить)» и этот файл. При совпадении ID сохраняется местная запись. Для точного восстановления резервной копии существует импорт с заменой: внимательно прочитайте подтверждение. Исходный JSON сохраните отдельно.

Если браузер не разрешает сохранение локальных файлов или показывает экран восстановления, используйте прежнюю закрытую веб-версию. Поддержка `file://` на реальном устройстве требует вашей проверки. Не считайте несохранённый текст сохранённым, если приложение показывает ошибку.

## Что осталось перед завершением

Проверьте удобство на настоящем iPhone, ввод текста с экранной клавиатурой и открытие создания Google-документа в своей учётной записи. Итоговая приёмка и решение об основном размещении принадлежат вам. Автоматически main и основной сайт не обновляются.

Заполненные направления показаны первыми; пустые при первом открытии свёрнуты. Ручное состояние раскрытия сохраняется.
