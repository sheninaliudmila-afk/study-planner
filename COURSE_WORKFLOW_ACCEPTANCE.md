# Курс → модули → занятия: протокол проверки, 08.11.2026

Основание — [уточнения владельца](requirements/course-workflow-2026-11-08.md). Ветка `stage3-goals-analytics-settings-2026-11-08`, [PR №2](https://github.com/sheninaliudmila-afk/study-planner/pull/2), аккаунт `sheninaliudmila-afk`.

## Готовое поведение

- «Обучение» открывает список курсов. Новый курс начинается с названия; далее цель, даты и необязательные предмет/преподаватель. После создания открывается курс с модулями, сроками, расписанием на ближайшие 30 дней и дедлайнами заданий.
- Модули можно запланировать целиком без занятий. Внутри выбранного модуля доступны занятия и задания. Модули используют прежние Topic ID; исходная иерархия доступна через «Структура по направлениям».
- Цель курса задаётся в самом курсе и следует его полному плану. Будущие конечные повторения не позволяют объявить курс завершённым раньше времени. Частичные задания считаются по точной доле шагов, 100% — только при полном выполнении. План и цель синхронны; даты сами ничего не завершают.
- Служебные действия вынесены под основные кнопки; иконки имеют aria-label, title и 44×44 px. Подтверждение удаления, резервные копии и Undo сохранены.
- Учёт времени скрыт по умолчанию. Его можно включить в настройках; он не меняет прогресс курса. Активный таймер и прежние записи времени сохраняются.
- Дедлайны курсов/модулей видны в календаре и внутристраничных напоминаниях. Фильтры курса/направления учитываются.

## Личные данные

Локально подготовлен самостоятельный HTML с найденной копией от 3 ноября и исходный резервный файл. Проверено сохранение каждого прежнего ID и каждого исходного поля, а не только количества записей. При пустом хранилище личная копия загружается; существующий ключ не заменяется. Есть подтверждаемое объединение отсутствующих записей с местными приоритетами и бэкапом.

Исходный JSON и личный HTML **не включены в GitHub**. В репозитории только общий упаковщик `build-personal-copy.cjs`, принимающий внешний путь к резервной копии. Его выход содержит личные данные и должен храниться отдельно от публичного исходного кода. Проверка упаковщика включает буквальный HTML, закрывающий тег script, Unicode и сохранение исходных байтов резервной копии.

Проверка настоящего личного комплекта выполняется в отдельном браузерном контексте на локальном HTTP-адресе; профиль владельца не открывается. Она не даёт доступа к более поздним данным iPhone. Копия датирована 3 ноября; более свежие браузерные записи могут отличаться.

## Ограничения и дальнейшая приёмка

Настоящие iPhone/Safari, VoiceOver и запись файла в папку устройства в этой Linux-среде недоступны. WebKit Linux не считается Safari iOS. Прямой file:// блокируется политикой управляемого Chromium, поэтому автономный HTML проверяется через локальный HTTP и отсутствие внешних ресурсов. Нельзя подтвердить изменения, сделанные в личном браузере после 3 ноября. Строгая атомарность всех гонок localStorage не обещается.

Main не изменён, PR не слит, сайт не опубликован. Шаг 4 — финальная сквозная приёмка — не объявляется завершённым.
